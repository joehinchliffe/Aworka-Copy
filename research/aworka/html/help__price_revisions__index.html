Prices

Create a set of standard priced Tasks. Create Price Revisions to update multiple job prices in one go.

How do I revise my job prices?

  • Click New Price Revision to enter details of the required price revision. Note that only jobs not assigned to tasks are affected.
  • Edit a Task price to affect all jobs performing the task.

How do I revert a Price Revision?

Click the Revert button in the Revert column of the price revisions table.

Note that each job can only be reverted from its most recent price revision.

What are Tasks?

A Task describes a common activity with a standard price and time required, e.g. a window cleaner might define a '3 Bed Semi' task with a standard price for all those jobs cleaning the windows of 3 bedroomed semi-detached houses.

The main advantages of using tasks:

  1. When creating a job, you only have to select the appropriate task, rather than reentering the same job description, price and time each time.
  2. Jobs performing the same task will be consistently priced from the Prices.
  3. Details of all jobs performing the same task can be updated in one go, by editing the task details once rather than each individual job.

How do I create a new Task?

Click New Task to enter new task details.

To use the task, create or edit a job and select a task from the Task popup menu.

How do I edit an existing task?

Click the Task name in the task list.

When a task is edited, all jobs performing the task will be updated to match.

Expenses

Record your expenses.

How do I record a new expense?

  1. Click New Expense
  2. Enter an expense Category, e.g. Travel, Stationery, Tools.
  3. Enter a Description of the expense if required, e.g. for an expense in the Travel category, you may wish to record destination or mileage.
  4. Adjust the date of the expense if required
  5. Enter the amount of the expense
  6. Click Save to create a new expense.

How do I edit an existing expense?

  1. Locate the expense to edit in the expenses table and click the link in the Category column.
  2. Edit the expense details as required.
  3. Click Save

If the expense is an automatically created recurring expense, you can click Monthly next to the expense date. Note that changes made to the recurring expense will not alter this one.

How do I view expenses for a different period?

  1. Choose the required period start or end date using the pull down menus for day, month and year
  2. Select Starting if the period starts at the specified date or Ending if it ends on specified date.
  3. Select duration of the period you are interested in.
  4. Click Refresh

How do I view all the expenses in one category?

  1. Select the category from the popup menu next to Show
  2. Click Refresh

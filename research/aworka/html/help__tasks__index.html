Show Task

Define standard tasks to describe many similar jobs.

  1. Enter a Name for the task, e.g. a dog walker might have tasks called 'Walk', 'Day Care', 'Overnight'
  2. Enter a Description for this task. This will be shown on invoices for jobs performing the task. If this is left blank, the Default Job Description value (if any) in your Settings will be used.
  3. Enter the Time required to perform the task.
  4. Enter the Price for jobs performing this task.
  5. Click Save

Users

Create Users and assign rounds (groups of jobs) to users.

How to I create a new User?

  1. Click New User
  2. Enter the new User's email address, which they will use to log in.
  3. Enter their Name and optionally, their Address and Phone number(s).
  4. Click Save to create the new account. The new user will receive an email with login instructions.

How to I edit an existing new User?

Click User's name in the users table.
